## 🌟 Обзор проекта

**QAIRU Games & AI Navigator** — это интерактивная платформа, призванная наглядно продемонстрировать работу фундаментальных алгоритмов искусственного интеллекта и дискретной математики. 

Вместо сухой теории проект предлагает **живой игровой опыт и практические симуляции**:
- Вычисление скрытых состояний невидимых врагов через фильтры частиц;
- Автономное принятие решений станцией на основе итерации ценностей (Value Iteration) в марковских процессах принятия решений;
- Построение оптимальных маршрутов по реальным улицам городов с бенчмарком 4 ключевых алгоритмов обхода графов;
- Локализация целей в условиях стохастического шума сенсоров.

## 🔬 Основные модули и алгоритмы

### 1. ⚡ Pulse Protocol FPS (Cyber-Grid 2099)
Полноценный 3D-шутер от первого лица с собственным программным **Raycasting-движком** (псевдо-3D на чистом Canvas 2D), разворачивающийся на космической станции.

* **Скрытые марковские модели (HMM) & Фильтр частиц (Particle Filter):**
  * Противники (паразиты) невидимы в темноте и отслеживаются сенсорами с высоким уровнем шума.
  * На каждую сигнатуру запускается ансамбль из **200 частиц**.
  * Каждый шаг выполняется цикл: **Prediction** (стохастический сдвиг частиц) → **Weighting** (взвешивание правдоподобия по шумным датчикам и сектору видимости фонаря) → **Resampling** (нормализация и регенерация частиц).
* **Марковские процессы принятия решений (MDP) & Value Iteration:**
  * Автопилот станции автономно управляет ресурсами (щиты, турели, ремонт модулей).
  * Решает уравнение Беллмана:  
    Q(s, a) = R(s, a) + \gamma \sum_{s'} P(s' \mid s, a) V(s'), \quad \gamma = 0.9
  * Пользователь в реальном времени может менять веса функции награды $R$: сохранение энергии, целостность модулей или уничтожение паразитов.
* **Стохастическая среда:** сенсоры ошибаются в 30% случаев, точность автоматической турели — 25%, случайные блуждания целей.

---

### 2. 🗺️ ИИ-Навигатор в реальном времени (GPS & Графы)
Интерактивная геоинформационная система на базе **Leaflet** и графа дорожной сети OpenStreetMap (через Overpass API с автономным fallback-генератором связной дорожной сетки).

* **Поддерживаемые алгоритмы поиска пути:**
  * **$A^*$ (A-Star Heuristic Search):** информированный поиск с функцией $f(n) = g(n) + w \cdot h(n)$. В интерфейс вынесен интерактивный регулятор веса $w \in [0; 3]$ (демонстрация допустимой эвристики при $w \le 1$ и ускоренного Weighted $A^*$ при $w > 1$).
  * **UCS / Алгоритм Дейкстры (Uniform Cost Search):** частный случай $A^*$ при $h(n) = 0$, гарантирующий строгую оптимальность маршрута по длине улиц.
  * **BFS (Поиск в ширину):** находит путь с минимальным числом перекрёстков (без учёта метрического расстояния).
  * **DFS (Поиск в глубину):** обход с возвратом (бэктрекинг), визуализирующий, почему жадный/глубокий обход неприменим для GPS-навигации.
* **⚡ Битва алгоритмов (Benchmark Mode):**
  * Параллельный запуск всех 4 алгоритмов на одной и той же паре координат.
  * Сводная таблица и гистограмма: количество исследованных узлов, итоговая длина пути, использование памяти (размер фронтира) и время вычисления в миллисекундах.
  * Возможность отобразить все 4 построенных маршрута на карте одновременно разными цветами.
* **Функции:** автоопределение текущего местоположения (HTML5 Geolocation API), интерактивное перетаскивание маркеров Старта (A) и Финиша (B), регулировка скорости визуализации волны поиска (1x, 4x, 12x, мгновенно).

### 3. ★ Охотник за кладом (Treasure Hunter)
Пошаговая тактическая головоломка в лабиринте.

* **Байесовский вывод (Bayesian Belief Updating):**
  * Сенсоры робота передают зашумленные показания («горячо», «тепло», «холодно»).
  * После каждого перемещения робот производит пересчет матрицы априорных/апостериорных вероятностей по формуле Байеса и визуализирует карту уверенности (тепловую карту вероятности нахождения сокровища).
* **Погоня на базе $A^*$:**
  * Противник (охранник) на каждом цикле пересчитывает кратчайший маршрут к игроку через $A^*$ по манхэттенскому расстоянию.
* **Режимы точного сканирования и подсказок оптимального пути.**

---

### 4. ◆ Игра «Память» (Memory Match)
Интерактивный тренажёр сопоставления сущностей, выступающий метафорой для:
* Векторных баз данных (Vector Databases);
* Поиска семантической близости (Cosine Similarity, k-NN);
* Эмбеддингов и сопоставления скрытых представлений.

---

### 🔊 Процедурный синтезатор звука (Web Audio API)
В проекте реализован собственный движок `SoundFX` на чистом **Web Audio API**:
* Все звуки (клики, шаги, сирены, выстрелы, радарный пинг, победные аккорды) синтезируются процедурно «на лету» (осцилляторы `sine`, `triangle`, огибающие амплитуды `GainNode`).
* Никаких внешних тяжелых MP3/WAV файлов — проект загружается мгновенно.

## 🚀 Установка и локальный запуск

### Вариант А: Через Python Flask (Рекомендуемый)

1. **Клонируйте репозиторий:**
   ```bash
   git clone https://github.com/Ruslan808-8/fun-ai-project.git
   cd fun-ai-project
   ```

2. **Создайте и активируйте виртуальное окружение:**
   * **Linux / macOS:**
     ```bash
     python3 -m venv venv
     source venv/bin/activate
     ```
   * **Windows:**
     ```powershell
     python -m venv venv
     .\venv\Scripts\activate
     ```

3. **Установите зависимости:**
   ```bash
   pip install -r requirements.txt
   ```

4. **Запустите сервер:**
   ```bash
   python flask_app.py
   ```

5. Откройте в браузере: **`http://localhost:5000`**

---

### Вариант Б: Чистый фронтенд (Live Server)

Так как весь интерактив и алгоритмы реализованы на стороне клиента, проект можно запустить без Python:
* Откройте `index.html` через расширение **Live Server** в VS Code / WebStorm;
* Либо используйте любой статический HTTP-сервер (например, `npx serve .` или `python -m http.server 8000`).

## 🌐 Деплой проекта

Приложение полностью готово к развертыванию на облачных платформах (**Render**, **Railway**, **PythonAnywhere**, **Heroku**):

* **Start Command:**
  ```bash
  gunicorn flask_app:app
  ```
* Сервер автоматически считывает переменную окружения `PORT` (по умолчанию `5000`).
