## 📌 О проекте

**QAIRU Games & AI Navigator** — это образовательная интерактивная веб-платформа, которая превращает абстрактные математические концепции искусственного интеллекта в наглядные игровые механики и симуляции реального времени.

Проект охватывает ключевые разделы классического курса **«Основы ИИ»**:
- Алгоритмы поиска пути на графах (неинформированные и информированные эвристические методы).
- Принятие решений в условиях неопределённости (стохастика, шумные датчики).
- Фильтрация и байесовский вывод скрытых состояний.
- Марковские процессы принятия решений (MDP) и обучение с подкреплением / динамическое программирование.

## 🎮 Ключевые модули и демонстрации

### 1. ⚡ Pulse Protocol FPS (HMM & MDP)
Научно-фантастический 3D-шутер от первого лица с псевдотрехмерным графическим движком (Raycasting / DDA в стиле Wolfenstein 3D):
* **Скрытые марковские модели (HMM) & Фильтр частиц (Particle Filter)**:
  * По станции перемещаются невидимые паразиты (сигнатуры $\alpha, \beta, \gamma, \delta$).
  * Положение каждой цели оценивается ансамблем из 200 частиц: предсказание движения, взвешивание по шумным датчикам расстояния (вероятность ошибки 30%) и лучу фонаря игрока, ресэмплинг.
* **MDP & Value Iteration (Итерация по ценностям)**:
  * Автопилот станции анализирует распределение вероятностей угроз и распределяет энергию между 4 действиями: *Экономия*, *Активация щита*, *Огонь турели* (стохастический урон с точностью 25%) и *Ремонт отсеков*.
  * Решение уравнения Беллмана в реальном времени:  
    $$Q(s, a) = R(s, a) + \gamma \sum_{s'} P(s' \mid s, a) V(s')$$
  * Пользователю доступны ползунки настройки функций наград и параметров модели.

### 2. ★ Охотник за кладом (Bayesian Filter & A*)
Тактическая 2D-головоломка на сетке $10 \times 10$:
* **Байесовский фильтр (Bayesian Inference)**:
  * Робот ищет спрятанный клад по зашумлённым подсказкам детектора (*«Горячо»*, *«Тепло»*, *«Холодно»*).
  * Матрица вероятностей учитывает погрешности измерений. После каждого шага алгоритм пересчитывает апостериорное распределение вероятностей по формуле Байеса и отрисовывает динамическую тепловую карту (heatmap).
* **Погоня на базе A\***:
  * ИИ-охранник преследует игрока по лабиринту из препятствий, динамически рассчитывая кратчайший путь с помощью алгоритма A* и манхэттенской эвристики.

### 4. 🗺️ ИИ-Навигатор в реальном времени (GPS & Сравнение алгоритмов)
Полноценная гео-навигационная система на базе **Leaflet.js** и реальной дорожной сети **OpenStreetMap (Overpass API)**:
* **Поддержка реальной геолокации**: кнопка *«Мой GPS»* определяет текущие координаты пользователя и строит граф дорог вокруг них (по умолчанию — район кампуса QAIRU в Алматы). Маркеры $A$ и $B$ можно произвольно перемещать кликом или перетаскиванием.
* **4 алгоритма поиска пути**:
  1. **A\* (A-Star)**: оценка $f(n) = g(n) + w \cdot h(n)$ с настраиваемым весом эвристики $w$ (допустимая эвристика при $w \le 1$, взвешенный A* при $w > 1$).
  2. **UCS / Дейкстра (Uniform Cost Search)**: гарантированно оптимальный поиск по длине улиц ($w = 0$).
  3. **BFS (Поиск в ширину)**: минимизация количества перекрёстков (очередь FIFO).
  4. **DFS (Поиск в глубину)**: обход с бэктрекингом (наглядно иллюстрирует петли и неоптимальность для задач навигации).
* **Визуализация фронтира**: анимированная отрисовка раскрытия узлов и очереди в реальном времени с регулировкой скорости (1x, 4x, 12x, мгновенно).
* **⚡ Режим «Битва алгоритмов» (Benchmark)**:
  * Одновременный прогон всех 4 алгоритмов на одном графе.
  * Формирование аналитической таблицы и столбчатой диаграммы: количество исследованных узлов, точная длина маршрута в метрах, гарантия оптимальности, пиковый размер фронтира (расход памяти) и время выполнения в миллисекундах.
  * Наложение всех 4 маршрутов на карту разными цветами для наглядного сравнения.

### 4. 💬 Интеграция с Telegram (Обратная связь)
* Всплывающий виджет обратной связи на главной странице.
* Backend-обработчик с защитой от спама (Rate limiting по IP — не чаще 1 запроса в 15 секунд), валидацией входных данных и отправкой сообщения через Telegram Bot API.

## 🛠️ Стек технологий

* **Frontend**:
  * Чистый HTML5, CSS3 (CSS Grid, Flexbox, CSS Custom Properties, адаптивный дизайн для мобильных и десктопов).
  * Vanilla JavaScript (ES6+, классы, async/await, Canvas 2D API).
  * [Leaflet.js](https://leafletjs.com/) — интерактивные карты и слои маршрутов.
  * **Web Audio API** — встроенный процедурный синтезатор звуковых эффектов (без тяжелых аудиофайлов).
* **Backend**:
  * [Python 3.10+](https://www.python.org/)
  * [Flask 3.0.3](https://palletsprojects.com/p/flask/) — маршрутизация, отдача статики и REST API.
  * [Gunicorn 22.0.0](https://gunicorn.org/) — WSGI HTTP-сервер для продакшн-развертывания.
  * **Telegram Bot API** (urllib / JSON) — мгновенные уведомления о багах и вопросах.
* **Данные и картография**:
  * OpenStreetMap / Overpass API (динамическая выгрузка геометрии улиц и перекрёстков).

## 🚀 Установка и запуск

### Вариант 1. Запуск с Flask (рекомендуется)

1. **Клонируйте репозиторий или перейдите в папку проекта**:
   ```bash
   cd "fun-ai project"
   ```

2. **Создайте и активируйте виртуальное окружение**:
   * *Windows (PowerShell)*:
     ```powershell
     python -m venv venv
     .\venv\Scripts\Activate.ps1
     ```
   * *Linux / macOS*:
     ```bash
     python3 -m venv venv
     source venv/bin/activate
     ```

3. **Установите зависимости**:
   ```bash
   pip install -r requirements.txt
   ```

4. **(Опционально) Настройте переменные окружения для Telegram-бота**:
   Если вы хотите получать сообщения из виджета техподдержки в Telegram:
   * *Windows (PowerShell)*:
     ```powershell
     $env:TG_BOT_TOKEN="ваш_токен_бота"
     $env:TG_CHAT_ID="ваш_chat_id"
     ```
   * *Linux / macOS*:
     ```bash
     export TG_BOT_TOKEN="ваш_токен_бота"
     export TG_CHAT_ID="ваш_chat_id"
     ```

5. **Запустите сервер**:
   ```bash
   python flask_app.py
   ```
   Откройте браузер по адресу: [http://localhost:5000](http://localhost:5000)

---

### Вариант 2. Быстрый запуск только клиентской части

Все игры и ИИ-Навигатор работают полностью на стороне клиента в браузере (за исключением отправки тикетов в Telegram):

```bash
# Python встроенный HTTP сервер:
python -m http.server 8000
```
Затем перейдите на [http://localhost:8000](http://localhost:8000).

## 🌐 Деплой на Render / PaaS

Проект готов к деплою на **Render**, **Railway** или любой VPS:
- **Build Command**: `pip install -r requirements.txt`
- **Start Command**: `gunicorn flask_app:app`
- **Environment Variables**:
  - `TG_BOT_TOKEN` — токен бота от `@BotFather`
  - `TG_CHAT_ID` — ID чата или группы для получения заявок
